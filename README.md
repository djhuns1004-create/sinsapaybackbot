# 신사 페이백봇 전체 안내문 수정형

## 관리자센터

관리자 계정에서:

```text
/admin
```

사용 가능한 기능:

- 전체 안내문 한 번에 수정
- 신청버튼 문구 수정
- 사진요청 문구 수정
- 계좌요청 문구 수정
- 신청완료 문구 수정
- 전체 안내문 미리보기
- 현재 안내문 백업
- 백업 안내문 복원
- 기본 안내문 초기화

## 전체 안내문 수정

`📝 전체 안내문 수정`을 누른 뒤 아래처럼 전체 내용을 한 번에 보내면 됩니다.

```text
💸 신사 주간 페이백 💸

📅 매주 월요일 ~ 일요일

💰 지급조건 💰

✨ 조건 1
✨ 조건 2

🎯 신청방법 🎯

🔥 신청 버튼 클릭
🔥 충전내역 첨부
🔥 계좌 작성

👀 관리자 확인 후 지급됩니다 👀
```

줄바꿈과 텔레그램 프리미엄 이모지를 그대로 저장합니다.

## 프리미엄 이모지

안내문, 사진요청, 계좌요청, 신청완료 문구에는 프리미엄 이모지를 사용할 수 있습니다.

텔레그램 API 제한상 실제 인라인 버튼 안에는 custom emoji 엔티티를 넣을 수 없습니다.
신청버튼 문구의 프리미엄 이모지는 버튼 바로 위 안내줄에서 프리미엄 형태로 표시되고,
실제 버튼에는 일반 이모지 또는 텍스트 형태로 표시됩니다.

## 이번 수정사항

- 안내문 아래에 신청 문구가 한 번 더 출력되던 중복 현상을 제거했습니다.
- `/start`와 관리자 미리보기에서 실제 인라인 신청 버튼만 한 번 표시됩니다.
- 버튼 문구는 관리자센터의 `신청버튼 문구`에서 계속 수정할 수 있습니다.
- 텔레그램 제한상 인라인 버튼 내부의 프리미엄 커스텀 이모지는 지원되지 않으므로 일반 이모지를 사용해야 합니다.

## 2026-10 통합 업데이트
- 기존 /start, /admin, 프리미엄 이모지/안내문 수정·백업·복원 유지
- 신청 주차(한국시간 월~일) 기록 및 동일 주차 중복 신청 차단 (거절 시 재신청 허용)
- 관리자 신청관리: 대기/승인/거절/지급 목록, 상세조회
- 승인 후 지급금액 입력, 지급완료(금액 필수), 거절 사유 입력
- 사용자 '내 신청내역' 버튼: 최근 5건 조회
- 관리자 이번 주 통계, 신청 접수 열기/닫기
- 입력 중 Railway 재시작 시에도 사진/진행상태 유지(SQLite drafts)
- 처리 기록(audit_log) 및 조건부 상태변경으로 중복 처리 방지
- /cancel 로 진행중 입력 취소

**중요**: 기존 DB를 유지하려면 Railway Volume 경로 `/data`와 `DB_PATH=/data/payback.db`를 변경하지 마세요. 배포 전 DB 백업을 권장합니다. 기존 applications 테이블에는 컬럼을 추가하며 기존 기록은 삭제하지 않습니다. 과거 기록에는 week_key가 없을 수 있습니다.

**운영 안내**: 신청은 기본적으로 항상 열려 있습니다. 접수 마감은 /admin에서 수동으로 전환합니다. 월요일 자동 마감/자동 오픈 기능은 포함하지 않았습니다. 주차만 자동으로 계산합니다. 실명/계좌정보는 DB에 저장되므로 Railway 접근 권한을 제한하고 불필요한 백업 파일을 외부에 공유하지 마세요.
